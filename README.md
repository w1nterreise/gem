# Gem

Легковесный десктопный ассистент для мгновенного взаимодействия с веб-интерфейсом https://google.com/ai.

---

## Управление и Горячие Клавиши

Управление вдохновлено терминалами, где [ЛКМ] и [ПКМ] используются для копирования и вставки.

*   **Отпускание ЛКМ** — Помещает выделенный текст в буфер обмена.
*   **Простой клик ПКМ** — Забирает текст из буфера обмена и отправляет в ИИ.

С помощью клавиш-модификаторов можно оборачивать текст из буфера обмена шаблонами промптов.

*   **Ctrl + ПКМ** — Открывает контекстное меню с вашими кастомными промптами-шаблонами из секции `[CTRL]`.
*   **Shift + ПКМ** — Открывает контекстное меню с шаблонами из секции `[SHIFT]`.
*   **Alt + ПКМ** — Открывает контекстное меню с шаблонами из секции `[ALT]`.
*   **Ctrl + Shift + ПКМ** — Пропускает перехват интерфейса и открывает нативное контекстное меню Chromium (WebView2).

## Конфигурация шаблонов промптов

Конфигурационный файл **`prompts.ini`** создается при первом вызове контекстного меню рядом с исполняемым файлом приложения. В релизе **`prompts.ini`** уже присутствует в архиве. Отредактируйте его, чтобы задать собственные шаблоны промптов.

### Правила синтаксиса файла:
1.  Строки, начинающиеся с символа `#`, считаются комментариями и полностью игнорируются парсером.
2.  Разделение промптов внутри секций `[CTRL]`, `[SHIFT]` и `[ALT]` происходит с помощью **двух переносов строки (одной пустой строки)**.
3.  Используйте плейсхолдер **`{clip}`** в любом месте вашего шаблона. При вызове команды Gem автоматически заменит его на содержимое буфера обмена.

Кэш промптов обновляется в оперативной памяти при изменении файла `prompts.ini`.

### Распознавание речи (STT)

Для распознавания задействованы библиотеки **Vosk** и **NAudio**:

* **Vosk Speech Recognition Toolkit**
  * **Автор:** [Alpha Cephei](https://alphacephei.com)
  * **Лицензия:** [Apache License 2.0](https://apache.org)
  *  В релизе используется модель `vosk-model-small-ru-0.22`.
  
Чтобы использовать другую модель, скачайте ее с https://alphacephei.com/vosk/models
Содержимое архива необходимо поместить в каталог `STT\model` так чтобы между `model` и файлом  README не было подкаталогов.
  
* **NAudio**
  * **Автор:** Mark Heath & Contributors ([GitHub](https://github.com/naudio))
  * **Лицензия:** [Microsoft Public License (Ms-PL)](https://opensource.org)

По умолчанию голосовой ввод осуществляется при зажатых клавишах **Ctrl + ~**. Отредактируйте **`Gem.exe.config`** чтобы задать другое сочетание клавиш.

При возникновении ошибки FileLoadException: Не удалось загрузить файл или сборку "...\STT\VoiceModule.dll" установите флажок "Разблокировать" в свойствах файла `VoiceModule.dll`.

**Модуль STT работает только в x64 архитектуре.**

## Возможные баги


### Бесконечная загрузка при авторизации Google
Встроенный контейнер Microsoft WebView2 из-за жестких правил изоляции кук иногда приостанавливает каскад внутренних редиректов безопасности Google сразу после успешного ввода пароля.
*   **Решение:** Если после ввода пароля страница авторизации зависла в бесконечной загрузке — просто нажмите кнопку **«Домой» (Home)** на верхней панели виджета Gem. Ваша сессия уже успешно сохранилась в контейнере, и приложение мгновенно перенаправит вас на рабочую страницу.

### Панель "История режима ИИ" отказывается уходить с экрана
Если в истории чатов выполнялись действия, сопровождающиеся открытием диалоговых окон ("Удалить", "Поделиться"), то фокус ввода приложения может заблокировать стандартный скрипт сворачивания боковой панели.
*   **Решение:** Кликните по любому чату в списке (например, по текущему активному). Это вернет фокус интерфейсу, и панель скроется.
